## About

PhantomDroid v2.2 is a Python-based device testing project designed for Android and iOS diagnostics, connectivity checks, and authorized device inspection.

## Testing Modules

- **Android ADB Testing**
  - Detect connected Android devices
  - Check ADB connection status
  - Display supported device information
  - Check USB debugging authorization

- **iOS Device Testing**
  - Check device connectivity using supported Apple tools
  - Display available device information
  - Perform basic device diagnostics

## Compatibility

| Platform | Target versions |
|---|---|
| Android | 11–17 |
| iOS | 18–26 |

## Requirements

- Python 3
- Android Debug Bridge (ADB) for Android testing
- Compatible Apple device utilities for iOS testing
- USB cable and authorized device access

## Disclaimer

This project is intended for educational purposes and authorized device testing only. Use it only on devices you own or have permission to inspect.
